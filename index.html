Glossário

HTML
HyperText Markup Language - Uma linguagem de marcação para a criação de páginas web.
CSS
Cascading Style Sheets - Uma linguagem de estilos utilizada para definir a aparência de páginas web.
C++
C Plus Plus - Uma linguagem de programação de alto nível, amplamente utilizada em desenvolvimento de software.
C#
C Sharp - Uma linguagem de programação desenvolvida pela Microsoft, utilizada para desenvolvimento de aplicações Windows e web.
MySQL

Git
Git - Um sistema de controle de versão distribuído, utilizado para gerenciar o histórico de alterações em projetos de software.
GitHub
GitHub - Uma plataforma de hospedagem de código-fonte e colaboração, que utiliza o Git como sistema de controle.
